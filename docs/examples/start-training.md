# Как начать тренировку по структурам данных

## Назначение

Инструкция предназначена для пользователя сервиса и помогает запустить тренировку начального уровня по теме «Структуры данных».

## Условия начала работы

Вы вошли в учётную запись. В каталоге доступна тема «Структуры данных». Названия разделов и элементов относятся к учебной модели интерфейса сервиса.

## Действия

1. Откройте раздел «Каталог».
2. Выберите тему «Структуры данных».
3. В списке «Уровень» выберите «Начальный».
4. Если для выбранных условий доступны задания, нажмите «Начать тренировку».

## Результат

Откроется первое задание. На странице появится обозначение текущего задания и общего количества заданий тренировки. Ответы и разбор доступны после отправки ответа на соответствующее задание.

## Если тренировка недоступна

Если по выбранным условиям заданий нет, сервис показывает сообщение «Нет заданий для выбранных условий». Выберите другой уровень либо вернитесь в каталог и выберите другую тему. Убедитесь, что появились доступные задания, затем нажмите «Начать тренировку».
