# Индекс первого максимального элемента

## Назначение

Задание предназначено для начинающих изучать Python. Требуются знания списков, циклов и индексов. Цель — отработать поиск элемента за один проход по списку.

## Условие

Реализуйте функцию `first_max_index(values)`. На вход передаётся список целых чисел от −1 000 000 до 1 000 000 включительно. Длина списка — от 0 до 10 000 элементов. Вход соответствует этим ограничениям; проверять другие типы данных не требуется. Исходный список изменять нельзя.

## Ожидаемый результат

Функция возвращает индекс первого вхождения максимального значения. Индексация начинается с нуля. Если максимальное значение встречается несколько раз, верните наименьший индекс. Для пустого списка верните `None` — специальное значение Python, обозначающее отсутствие результата.

## Примеры

1. Вход: [3, 7, 7, 2]. Результат: 1, поскольку первое максимальное значение находится по индексу 1.
2. Вход: [-5, -2, -9]. Результат: 1.
3. Вход: []. Результат: `None`.

## Разбор

Если список пуст, результат отсутствует. Иначе запомните индекс первого элемента как лучший найденный индекс. Последовательно сравнивайте следующие элементы с лучшим. Обновляйте индекс только при строго большем значении. При равенстве сохраняйте прежний индекс, поэтому результат указывает на первое вхождение максимума.

## Решение

Среда выполнения: Python 3.12. Функция получает список аргументом и возвращает результат; ввод с клавиатуры не требуется.

```python
def first_max_index(values: list[int]) -> int | None:
    if not values:
        return None
    best = 0
    for index in range(1, len(values)):
        if values[index] > values[best]:
            best = index
    return best
```

## Проверка

Проверяются пустой список, один элемент, отрицательные числа, повторяющийся максимум, одинаковые элементы, максимум в начале и максимум в конце. Для каждого случая проверяется возвращаемое значение и отсутствие изменения исходного списка.

## Сложность и типичные ошибки

Для n элементов время работы составляет O(n): каждый элемент просматривается не более одного раза. Дополнительная память составляет O(1): число вспомогательных переменных не зависит от длины списка. Для пустого списка время работы постоянно.
Замена сравнения `>` на `>=` приведёт к выбору последнего максимума. Начальное значение максимума, равное нулю, может дать неверный ответ для отрицательных чисел. Обращение к первому элементу без проверки пустого списка приведёт к ошибке.
