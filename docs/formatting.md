# Структура и оформление материалов

## П06. Заголовки

В Markdown используйте один заголовок с символом #, разделы обозначайте ##, подразделы — ###; уровни не пропускайте. Заголовок должен называть задачу или предмет: «Как начать тренировку», «Входные данные». Не заменяйте заголовки выделением жирным шрифтом.

## П07. Шаги инструкции

В шаге сначала указывайте место действия, если оно ещё не определено, затем действие: «В разделе „Каталог“ выберите тему». Один шаг должен содержать одно основное действие. После последнего шага указывайте наблюдаемый результат. Слова «нажмите здесь» без названия элемента не используйте.

## П08. Списки и таблицы

В исходном Markdown последовательность действий оформляйте нумерованным списком, независимые условия — маркированным. Полные предложения начинайте с прописной буквы и завершайте точкой. Таблицы используйте для повторяющихся записей с одинаковыми полями, обязательно называйте столбцы. Длинные объяснения выносите из таблицы в текст.

## П09. Ссылки и изображения

По подписи ссылки должно быть понятно её назначение: «Описание условий задания», а не «Подробнее здесь». Проверяйте адрес перед публикацией. Для изображения задавайте альтернативный текст и поясняйте его смысл в основном тексте. Скриншот дополняет инструкцию и не заменяет шаги. Элемент интерфейса называйте по подписи, а не только по цвету или расположению.

## П10. Примеры кода

Блок кода в Markdown ограничивайте тройными обратными кавычками и указывайте язык. Перед примером называйте проверенную версию среды. Отделяйте ввод, код и ожидаемый вывод; неполный пример обозначайте как фрагмент. Выполняемые примеры проверяйте до публикации. Секреты заменяйте явно обозначенными фиктивными значениями. Проверяйте, что пример не требует неописанных файлов или настроек.

На сайте документации используйте стандартные стили темы, без ручной окраски текста. Жирным можно выделить важное условие, моноширинным — имя функции или параметра. При включении материала в учебный отчёт применяются требования его оформления: основной текст Times New Roman 14 пт, интервал 1,5; программный код оформляется листингом с подписью, моноширинным шрифтом и сохранением отступов.
