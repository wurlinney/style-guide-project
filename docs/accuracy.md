# Ошибки и достоверность

## П15. Сообщения об ошибках

Сообщение о проблеме должно описывать её наблюдаемый признак и следующее действие. Причину указывайте только при наличии подтверждения. Пример: «Нет заданий для выбранных условий. Выберите другой уровень или тему». Не обвиняйте пользователя и не обещайте гарантированный успех после действия, которое его не обеспечивает.

## П16. Проверка фактов

Сверяйте названия и поведение с действующей версией продукта, алгоритмы — с условием задачи и проверками. Для заимствованного объяснения указывайте источник. Авторский пример можно обозначить как учебный. Если описывается учебная модель продукта, заранее фиксируйте её интерфейс и не представляйте предполагаемое поведение как результат проверки работающего сервиса.
