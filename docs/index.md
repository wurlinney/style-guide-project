# О руководстве

Руководство применяется к пользовательским инструкциям, учебным вопросам, практическим заданиям, разборам решений и технической документации сервиса. Авторы — разработчики и редакторы учебных материалов. Читатели — пользователи сервиса и участники технической команды. Для пользователя объясняйте действия и результат; для разработчика дополнительно раскрывайте условия выполнения и ограничения.

Общие правила П01–П10, П15–П18 действуют в пределах своей области применения; из правил П11–П14 выбирается шаблон нужного вида документа. Если правило неприменимо, проверяющий указывает причину. Пример кода и точная надпись интерфейса имеют приоритет перед общими правилами языка. Это исключение не разрешает произвольно менять терминологию поясняющего текста.

## Учебная модель сервиса

Объект руководства — веб-сервис подготовки к техническим собеседованиям. Предполагаются каталог тем, выбор уровня, тренировки, практические задания, разборы и отслеживание прогресса. Это модель для лабораторной работы; работающего сервиса и подтверждённого API пока нет.

## Как пользоваться руководством

1. Проверьте [язык и терминологию](language.md).
2. Оформите материал по [общим правилам](formatting.md).
3. Выберите [шаблон документа](templates.md).
4. Проверьте [достоверность утверждений](accuracy.md).
5. Проверьте [доступность текста](accessibility.md).
6. Пройдите [проверку перед публикацией](maintenance.md).
